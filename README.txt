情书 —— 永久公开网页
================================

【永久地址：任何人、任何网络都能打开】
https://newboss776.github.io/love-letter/

手机扫码：qr.png
电脑/手机浏览器直接输上面的网址也可以。

这个版本部署在 GitHub Pages 上，不依赖这台电脑。
电脑关机、断网、关掉任何窗口，网址都仍然有效。

【源码仓库】
https://github.com/newboss776/love-letter
以后要改内容，替换仓库里的 index.html 即可；两段音乐是 intro.m4a 和 bgm.m4a。

【怎么玩】
- 封面是“情书”和一颗跳动的粉红心脏。
- 在封面上连续点 100 下，每点一下都有反馈。
  安卓会震动；iPhone 的 Safari 不开放网页震动接口，用很轻的“嗒”声替代。
- 点满 100 下之前，播放一段轻柔的浪漫音乐盒循环（intro.m4a），让你慢慢点。
- 点满 100 下后：心脏爆裂 → 白光、裂纹、冲击波 → 满屏“上旋律”。
  这时才真正开始播放你给的抖音 BGM（bgm.m4a），从开头循环。
- 右上角两个圆钮：左边静音/取消静音，右边重新开始。
- 最终画面点一下会有抖动反馈。

【文件】
- index.html        页面本体（HTML/CSS/JS 全在里面）
- intro.m4a         前 100 次点击时的浪漫音乐盒循环（本地合成，26.67 秒）
- bgm.m4a           点满 100 下后播放的抖音原声（25.47 秒，AAC，循环）
- qr.png            永久地址二维码
- qr-lan.png        旧的局域网地址二维码（备用）
- start-server.bat  本地预览用（可选）
- start-public.bat  旧的临时公网隧道脚本（已不需要）
- shots/            手机尺寸效果截图（可删）

【小提示】
- iPhone 打开静音拨片时，网页音乐可能没有声音，请关掉侧边静音、调大音量。
- 建议用 Safari / Chrome / Edge 打开。
- BGM 仅作个人娱乐使用，版权归原作者所有。
